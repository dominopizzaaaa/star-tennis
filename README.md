# Star Tennis Singapore — Concept Redesign

A premium, responsive redesign concept for [Star Tennis Singapore](https://www.startennis.sg/), built as a lightweight static site and published with GitHub Pages.

## Highlights

- Editorial sports-inspired visual system using the established Star Tennis oxblood palette
- Authentic Star Tennis photography, logo and favicon
- Responsive layouts for desktop, tablet and mobile
- Accessible navigation, accordions, level selector and reduced-motion support
- Direct booking, registration, WhatsApp and social links
- SEO metadata and structured business data
- Zero framework or runtime dependencies

## Local preview

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Asset note

Brand assets and photography are sourced from the existing Star Tennis website for this redesign concept. All underlying brand and image rights remain with their respective owners.
